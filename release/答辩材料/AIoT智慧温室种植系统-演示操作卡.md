# AIoT 智慧温室种植系统 - 演示操作卡

## 答辩前 2 分钟

- [ ] 用 Chrome 或 Edge 打开 `AIoT智慧温室种植系统-离线答辩版.html`
- [ ] 浏览器全屏，确认未显示开发者工具或本机路径
- [ ] 进入“数据总览”，点击“答辩复位”
- [ ] 确认：正常运行、模拟已暂停、固定种子、步数 0
- [ ] 确认：运行模式为答辩仿真，数据为本地模拟通道
- [ ] 测试一次“单步推进”后再次点击“答辩复位”
- [ ] 确认“报警中心”可导出，确认“导出演示快照”可用

## 现场操作顺序（约 2 分 30 秒）

1. 【操作】点击“答辩复位”。
   - 说明：固定种子、暂停状态和步数归零，使演示可复现。
2. 【操作】选择“土壤干旱” → 点击“单步推进”。
   - 说明：有效湿度数据触发报警与灌溉目标，水泵模拟确认执行后湿度会恢复。
3. 【操作】选择“水泵故障” → 点击“单步推进”。
   - 说明：目标为开启，但实际状态未运行，控制通道失败并报警；不伪造成功。
4. 【操作】选择“传感器离线” → 点击“单步推进” → 打开“环境监测”。
   - 说明：质量为 offline，读数不参与自动控制。
5. 【操作】打开“报警中心” → 选择筛选条件 → 点击“导出全部”。
   - 说明：报警可筛选和导出 UTF-8 BOM CSV。
6. 【操作】回到“数据总览” → 点击“导出演示快照”。
   - 说明：快照可导出；导入前会严格校验。

## 异常处理

- 页面状态不符合预期：点击“答辩复位”。
- 离线文件打不开：换 Chrome 或 Edge；不要用源码入口 `index.html`。
- 演示时间不足：保留土壤干旱和水泵故障，口头说明传感器离线逻辑。
