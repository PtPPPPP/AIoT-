# AIoT 智慧温室答辩版使用说明

1. 推荐用 Chrome 或 Edge 双击打开 `AIoT智慧温室种植系统-离线答辩版.html`。
2. 进入数据总览，点击“答辩复位”，确认正常运行、暂停和固定种子。
3. 推荐顺序：正常运行 → 土壤干旱 → 水泵故障 → 传感器离线 → 报警筛选导出 → 快照导出。
4. 报警中心可导出当前筛选结果或全部记录 CSV；控制台可导出快照和操作记录。
5. 当前是本地模拟模式，真实传感器、控制器、MQTT、数据库和远程 AI 均未接入。
6. 出现异常时再次点击“答辩复位”；若页面无法打开，重新执行 `npm run build:offline && node scripts/prepare-release.mjs`。
