# AIoT 智慧温室种植系统

这是一个面向大学生竞赛答辩展示的可运行产品原型。系统用模拟传感器、模拟设备和模拟 AI 识别结果，展示智慧温室中的“数据采集 - 智能分析 - 自动执行 - 反馈优化”闭环。

## 项目来源

原型参考了资料目录 `C:\Users\10748\Desktop\农耕算法大创申报` 中的申报书、开题报告和 PPT 内容。资料重点包括：温室绿色番茄识别、YieldNet 轻量化视觉模型、无人机/传感器多源数据、空地协同核验、智能农业决策和远程监控。

## 功能模块

- 数据总览：展示温度、湿度、光照、土壤湿度、CO₂、报警数量、灌溉次数、节水率、节能率和实时曲线。
- 环境监测：展示多传感器实时数据，异常数据自动高亮。
- 智能控制：支持自动/手动模式，展示水泵、风扇、补光灯、遮阳设备状态和控制规则。
- AI识别：支持选择样例或上传图片，模拟“AI分析中 - 识别完成 - 生成建议”的流程。
- 报警中心：展示土壤缺水、温度过高、光照不足、设备异常、病害风险等报警，并支持标记已处理。
- 设备管理：展示传感器、摄像头、水泵、风扇、补光灯、网关等 IoT 设备，并支持模拟在线/离线。
- 项目介绍：用于比赛申报和路演展示，包含背景意义、系统架构、核心功能、创新点和应用场景。

## 演示流程

1. 打开“数据总览”，说明系统实时采集温室环境数据。
2. 进入“环境监测”，展示异常高亮，例如土壤湿度偏低、光照不足。
3. 进入“智能控制”，打开自动模式，说明系统会根据阈值控制水泵、风扇、补光灯和遮阳设备。
4. 进入“AI识别”，选择“叶片疑似病斑”并点击开始分析，展示病害风险识别和处理建议。
5. 进入“报警中心”，展示 AI 或环境异常生成的报警，并标记为已处理。
6. 进入“设备管理”，模拟设备离线，说明 IoT 联网管理能力。
7. 进入“项目介绍”，用于申报系统填写和现场答辩收尾。

## 后续接入真实系统

- 硬件接入：用 MQTT、HTTP 或 WebSocket 接入温湿度、光照、土壤湿度、CO₂、摄像头和控制器数据。
- 控制接入：把当前前端设备开关对接到继电器、PLC、LoRa 网关或边缘控制盒。
- AI模型接入：将模拟 AI 结果替换为 YieldNet/YOLO 推理服务，输入摄像头图片，输出检测框、健康评分和病害风险。
- 数据存储：增加后端和数据库，保存历史环境数据、报警记录、设备日志和 AI 识别结果。
- 边缘部署：将模型量化后部署到 Jetson、树莓派或国产边缘计算板卡，实现低成本现场运行。
