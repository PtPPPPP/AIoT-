# 可替换边缘计算节点部署说明

## 定位与当前状态

项目不绑定 MIC-711D，也不把任何特定开发板当作系统成立的前提。当前原型阶段使用普通 Windows 笔记本或台式机作为参考边缘计算节点；它可以运行项目自定义边缘网关、控制策略服务、数据存储、AI 推理客户端和 React 页面。未来可迁移到 Jetson、工业计算机或其他兼容平台。

当前仍未连接真实 WISE-4012、ADAM-6050、EKI-2525、传感器、继电器、摄像头或真实 AI 模型。软件接口已预留不等于硬件已上线。

## 五层架构

1. 现场感知层：WISE-4012 计划采集温度、湿度、土壤湿度、CO₂ 和光照。
2. 现场控制层：ADAM-6050 计划读取低液位、设备反馈、限位、急停等数字输入，并输出水泵、风机、补光和遮阳控制信号。
3. 工业网络层：路由器或 Wi-Fi AP 连接无线采集设备，EKI-2525 提供工业以太网交换。
4. 边缘计算层：可替换节点运行网关、确定性控制、数据存储和可替换 AI 推理提供者。
5. 应用展示层：React 页面展示数据、设备、报警、AI 结果和配置状态。

```text
传感器 → WISE-4012 → Wi-Fi / 局域网 → 路由器或 AP → EKI-2525
                                                        ├─ ADAM-6050
                                                        └─ 可替换边缘节点
                                                           ├─ 边缘网关
                                                           ├─ 控制策略
                                                           ├─ 数据存储
                                                           ├─ AI 推理
                                                           └─ React 控制平台
```

## Windows 参考部署

Windows 计算机与 EKI-2525 接入同一受控局域网。项目自定义边缘网关监听局域网地址，React 前端只通过 HTTP/WebSocket 访问网关。网关再负责 REST、MQTT 或 Modbus TCP 适配，并统一执行鉴权、重试、数据校验、设备映射和安全控制。

当前仓库只实现前端客户端和协议校验，不包含正式网关服务。`.env.example` 中的地址是配置示例，不证明服务已经运行。连接成功必须以 `GET /api/v1/health` 和后续有效数据为准。

## 职责边界

边缘网关负责：

- 连接 WISE-4012、ADAM-6050 等现场设备；
- 保存设备凭据、MQTT 凭据和 Modbus 配置；
- 将设备协议转换成稳定的项目 API；
- 校验命令、维护幂等性、超时、互锁和故障状态；
- 提供传感器、执行器、健康状态和 AI 推理接口。

React 前端不负责：

- 直接访问研华设备或 Modbus 寄存器；
- 保存密码、Token、设备密钥或 MQTT 凭据；
- 根据节点类型推断设备已经连接；
- 承担低液位、限位、急停、电气互锁等安全逻辑；
- 让 AI 结果直接控制水泵、风机、补光或遮阳。

AI 推理服务负责图像预处理、模型执行、结果格式化和错误报告。当前 simulation 提供者仅生成明确标注的离线演示结果；edge-gateway 提供者只实现 `POST /api/v1/ai/infer` 客户端、DTO 和运行时校验，不包含真实模型。

## simulation 与 external

- `simulation`：使用本地模拟数据、模拟控制回执和模拟 AI，不访问外部网关，适合离线答辩。
- `external`：使用项目自定义边缘网关。缺少地址时保持 `unconfigured`，不会回退到模拟数据，也不会显示已连接。
- `playback`：保留本地回放类型，不等同于节点类型，目前不建立外部连接。

运行模式与节点类型互相独立。`local-pc`、`industrial-pc`、`jetson`、`remote-server` 只说明部署位置，不能代替健康检查。

## 迁移到 Jetson 或工业计算机

1. 保持项目网关 API 和 DTO 不变。
2. 为目标操作系统配置服务启动和进程守护。
3. 按目标硬件选择 CPU、GPU 或其他推理后端。
4. 安装并验证摄像头驱动和图像采集链路。
5. 迁移设备凭据到网关侧安全配置，不放入前端环境变量。
6. 完成 WISE-4012、ADAM-6050 联调及断网、断电、低液位、限位、急停和互锁测试。
7. 只有健康检查、数据上报和现场安全测试通过后，页面才可显示真实在线状态。

与硬件平台相关的是操作系统、服务启动、GPU 推理后端和摄像头驱动。与硬件平台无关的是网关 API、DTO、确定性控制规则、React 页面和数据库模型。
