# 运行可信度与边缘协议

2026-10-19：本文件描述已实现的软件边界与待边缘服务实现的能力。现场网关、接线和物理反馈未在本次任务中验证。

## 已实现的兼容扩展

传感器 DTO 仍是 schemaVersion: 1，新增可选 sourceKind：
- hardware：网关声明来自硬件采集，界面仍标“待现场核验”。
- simulation：仿真；playback：回放；unknown 或省略：来源待核实。
- 旧接口不声明来源时不升级为“真实数据”。仅 source 精确为 simulation/playback 时按对应类型归类，其他自由文本不推断为硬件证据。
- 每项指标独立保存 sourceId、source、capturedAt、receivedAt、最后有效时间和最后有效值。收到重复旧时间戳不会延长数据有效期；过远未来时间标记无效；倒序采样忽略。
- 网关响应中的 valid、quality、值、时间和枚举仍经过运行时校验。
- 外部自动策略要求所用指标均声明 hardware 且质量有效。来源不明确时仍可监测，不能以仿真指标驱动外部自动控制。

GET /api/v1/actuators 是逻辑设备数组，每项包含 logicalDevice、online、updatedAt，可选 target、actual。新增可选 sourceKind 与 feedbackLevel：
- gateway 或省略：网关状态，未说明反馈来自何处；
- output：输出通道回读，不等于执行器动作；
- physical：网关声明来自物理反馈，仍需现场验证接线、有效电平与时间同步。

缺少 actual 时不生成布尔反馈；断线或缺少新的反馈时保留最后已知值与时间并标记过期。传感器与执行器分别轮询，一项失败不伪造另一项状态。设备列表中的位置来自现有配置，外部上报 ID 通过逻辑指标／设备对应，现场位置需要核实。

POST /api/v1/control/commands 仍使用现有命令 ID、幂等键、创建时间与等待时限。回执 actual 改为可选：acknowledged 只表示网关接受；succeeded 是网关报告成功，未声明物理反馈时不能宣称动作确认。身份、目标不匹配或响应无效视为失败。旧回执不会覆盖较新命令。

前端等待时限只负责呈现回执超时，不负责设备停机保护。已接受但未取得最终回执的命令在等待时限后显示超时，保留最后反馈；不自动重发。

## 连接与授权

初始 GET health 和 actuators 同步是只读流程；失败后每 5 秒重新尝试。同步成功后按配置轮询 sensors/latest 和 actuators。未在本轮访问现场服务，GET 接口无控制副作用是协议要求，仍需独立服务实现遵守。

external 默认只监测；每次页面会话需显式授权控制，刷新不恢复授权，通信失败／过期／部分失联撤销授权。已验证的现有阈值与禁用映射示例没有变更。browser 策略依赖页面运行，不作为无人值守控制器。

## 尚未生效的边缘接管／保护设计

以下是协议设计，当前没有发送这些请求，也不显示保护已经生效：

1. 网关提供能力声明：租约接管、设备最长运行时限、失效保护、持久化与重启恢复、反馈层级、服务启动标识。
2. 租约请求包括 leaseId、设备范围、服务端确认的 expiresAt、按设备配置的到期行为、策略版本；由网关鉴权与幂等处理。
3. 网关持久化租约、目标与执行日志。租约超时、浏览器退出、掉线和服务重启均独立处理；返回生效状态与实际反馈。
4. 各设备保护策略依据现场风险与联锁确认；不统一关闭所有设备，不把网络错误等同执行器停止。
5. 前端在未收到能力声明和生效回执前，只显示“未验证／未生效”。最长连续运行、低液位、限位和急停必须在边缘／控制器／电气回路执行。
6. 重启恢复必须报告新的执行器快照与启动标识；应通过 mock 服务重启、断网、超时和执行器异常的隔离测试，再单独授权现场验证。

## 当前数据限制

没有后端历史接口；localStorage 仅用于当前浏览器的有界记录，不是可靠工控审计系统。报警与控制记录按设备键和时间窗口关联，界面明确为“期间关联记录”，不宣称严格因果。无账号身份，不虚构操作人员。回放仅有类型与控制隔离，未实现完整时间轴。
